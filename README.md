# Ruta Cloud & Data Engineering — Carlos Villanueva

Repositorio de trabajo de una ruta de 39 semanas desde analítica y BI hacia
ingeniería de datos en la nube (Azure · Databricks · Spark · Delta Lake),
construida sobre **un solo proyecto acumulativo**: un pipeline de KPIs de
operación NOC.

- **El contrato de la ruta está en [`CLAUDE.md`](CLAUDE.md)** — rol del mentor,
  fases, reglas del repositorio. Se lee al inicio de cada sesión.
- **El avance sesión a sesión está en [`BITACORA.md`](BITACORA.md).**
- **Cada fase vive en [`fases/`](fases/)** con su temario, labs y entregable.

| Fase | Tema | Semanas |
|---|---|---|
| [F0](fases/f0-git-fundamentos/) | Git profesional y fundamentos | 1–3 |
| [F1](fases/f1-nube-costos/) | Nube y costos reales | 4–6 |
| [F2](fases/f2-delta-lake/) | Delta Lake por dentro | 7–11 |
| [F3](fases/f3-spark-internals/) | Spark: internals | 12–19 |
| [F4](fases/f4-ingesta-streaming/) | Ingesta, streaming y orquestación | 20–25 |
| [F5](fases/f5-produccion/) | Producción: pruebas, despliegue, monitoreo | 26–30 |
| [F6](fases/f6-gobierno-semantica/) | Gobierno, seguridad y capa semántica | 31–34 |
| [F7](fases/f7-certificacion-cierre/) | Certificación, AWS y cierre | 35–39 |

> Los datos no se versionan. `datos/` está ignorado; lo que se versiona es el
> generador sintético, no su salida.
