      Último paso · Cerrar

      Ahora hazlo de verdad

      El simulador ya lo sabes. Lo que se entrega es la traza de un repositorio real: rango, pasos, criterio de decisión y —lo único que no se puede automatizar— por qué ese cambio produce ese síntoma.

      1 · monta el laboratorio

      Cuatro líneas en la terminal. El primer comando construye un repositorio desechable con el defecto ya sembrado; se puede rehacer las veces que quieras.

      python3 fases/f0-git-fundamentos/labs/lab-bisect/montar-laboratorio.py cd datos/lab-bisect/repo git bisect start HEAD informe-semana-40 git bisect run ../prueba.sh

      Antes de git bisect reset: git bisect log > /tmp/traza.txt. Eso es lo que vas a pegar aquí abajo.

      2 · pega lo que devolvió bisect

      Se lee aquí en tu navegador. No se envía a ningún lado.
      Lo da git rev-list --count informe-semana-40..HEAD. Sirve para comparar tus pasos con log₂(n).
