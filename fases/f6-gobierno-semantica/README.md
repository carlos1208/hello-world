# F6 · Gobierno, seguridad y capa semántica
**Semanas 31–34 · 40 h**

## Objetivo
Cerrar el circuito hasta donde ya eres fuerte, pero con la capa de gobierno que
exige un entorno profesional real.

## Gobierno y seguridad
- [ ] Unity Catalog: metastore, catálogos, esquemas y el modelo de permisos en tres niveles
      — *17% del examen Professional entre seguridad y gobierno*
- [ ] Linaje de datos: rastrear un indicador del tablero hasta la alarma cruda
      — *lo primero que pide una auditoría* → `docs/linaje/`
- [ ] Control de acceso por filas y enmascaramiento de columnas
      — *un analista regional no debería ver los nodos de otra región*
- [ ] Compartición y federación: exponer datos sin copiarlos

## Capa semántica
- [ ] Dónde vive la definición de un KPI y por qué no puede vivir en cada informe
      — *si cada reporte define «disponibilidad» distinto, no hay verdad única*
- [ ] Microsoft Learn — ingeniería de datos con Fabric (DP-700), por el conocimiento,
      no por el examen · https://learn.microsoft.com/en-us/training/courses/dp-700t00
- [ ] **Lab** · Power BI sobre la capa oro, con el modelo semántico definido una sola vez
- [ ] **Lab** · Tablero de KPIs NOC: MTTR, reincidencia, disponibilidad por zona
      — *mediana, no promedio: la cola de tiempos de resolución es larga*
- [ ] **Lab** · Documento de linaje completo, de la alarma cruda al indicador

## Entregable
Catálogo gobernado con permisos por rol, tablero de KPIs sobre el modelo semántico
único, y documento de linaje de cada indicador.

## Puente con tu perfil
Aquí tu perfil se vuelve poco común: hay ingenieros que construyen pipelines sin
entender qué necesita el negocio, y analistas que no pueden tocar lo que está aguas
arriba. Terminar esta fase te pone en el cruce.
