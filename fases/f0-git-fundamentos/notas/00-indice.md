# Módulo 1 — capa profesional

Orden de lectura. Cada nota cierra con autoevaluación: si no la respondes sin
buscar, la nota no está cerrada.

1. [El modelo de objetos](01-modelo-de-objetos.md) — blob, tree, commit e
   inmutabilidad. Es la base de las otras tres.
2. [`reflog`](02-reflog.md) — recuperar lo que creías perdido. Se lee antes de
   rebase a propósito: es la red debajo del trapecio.
3. [Rebase interactivo](03-rebase-interactivo.md) — dejar un historial que se
   pueda bisectar.
4. [`git bisect`](04-bisect.md) — encontrar el commit culpable por búsqueda
   binaria.

Después: el [laboratorio de bisect](../labs/lab-bisect/) y el
[entregable](../entregable/traza-bisect.md).

**Plataforma interactiva de este módulo:** ver `fases/f0-git-fundamentos/README.md`.
