# La plataforma se movió

El código de la plataforma interactiva vive ahora en **`/app`**, en la raíz del
repositorio, porque además de publicarse como artefacto de Claude se despliega
como sitio propio en Netlify.

- `app/modulo-1.html` — esta fase
- `app/glosario.js` — glosario compartido de toda la ruta
- `app/almacenamiento.js` — progreso: local, artefacto o nube
- `app/tutor.js` — el botón «no lo entendí»

Pasos de despliegue: [`docs/despliegue.md`](../../docs/despliegue.md).
