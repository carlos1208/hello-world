# F7 · Certificación, segunda nube y cierre
**Semanas 35–39 · 50 h**

## Objetivo
Convertir 34 semanas en **tres activos**: una certificación reconocida, un
portafolio público y un servicio que Nexora puede vender.

## Certificación
- [ ] Repaso con el curso oficial gratuito y simulacros
      — *dos simulacros con 80% o más antes de agendar*
- [ ] Presentar **Databricks Certified Data Engineer Associate** · USD 200 · 2 años
      de vigencia · https://www.databricks.com/learn/certification/data-engineer-associate
- [ ] Decisión informada sobre el **Professional**, con el temario cubierto en ~60%
      — USD 200, 59 preguntas, 120 minutos. *Se decide aquí, con experiencia encima,
      no ahora* · https://www.databricks.com/learn/certification/data-engineer-professional

## Segunda nube por transferencia
- [ ] Mapa de equivalencias Azure → AWS: ADLS/S3, Data Factory/Glue, Synapse/Redshift
      — *no se reaprende nada: se traduce lo que ya sabes*
- [ ] AWS Skill Builder — plan de ingeniería de datos, módulos de fundamentos · https://skillbuilder.aws/learning-plan/FYGBWGX6QJ/data-engineering-on-aws-learning-plans-includes-labs/7UPVWWCC45
- [ ] **Lab** · Replicar la capa de ingesta del pipeline en AWS
      — *suficiente para sustentarlo en entrevista sin exagerar tu nivel*

## Cierre
- [ ] Publicar el repositorio con documentación, arquitectura y decisiones justificadas
      — **en inglés**; es lo que va a leer un reclutador remoto
- [ ] Escribir el caso de estudio como oferta de servicio de Nexora
- [ ] Actualizar currículum y titular de LinkedIn con el perfil ampliado

## Entregable
Certificación aprobada, repositorio público documentado, caso de estudio comercial
y currículum actualizado.

## Puente con tu perfil
El mismo proyecto sirve para las tres cosas que pediste, en el orden que elegiste:
portafolio, certificación y servicio empaquetado. No son tres esfuerzos: es uno con
tres salidas.
